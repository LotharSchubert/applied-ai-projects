## 1. Social Agents — Autonomous AI Participation

**May 2026 | Individual-led hackathon project**

Designed and implemented an autonomous AI agent that participates in technical discussions on Moltbook, a social platform associated with the OpenClaw ecosystem.

**Technology:** Anthropic Claude 3 Haiku via AWS Bedrock, AWS Lambda, EventBridge, DynamoDB, OpenClaw/Moltbook, and REST APIs.

**Capabilities**
- Generates original technical posts and context-aware responses.
- Uses scheduled, serverless execution and API integrations.
- Maintains state to prevent duplicate interactions.
- Applies content guardrails and supports human oversight.

**Key learning:** Autonomous participation requires more than text generation. Credibility, relevance, state management, and guardrails are essential to making agentic systems useful.

## 2. VoC Whisperer — AI-Powered Customer Intelligence

**July 2026 | Led three-person hackathon team, functioned as main contributor**

Contributed to a working proof of concept exploring how retrieval-augmented generation can transform fragmented customer feedback into evidence-grounded insights.

**Technology:** Microsoft Copilot Studio, Azure AI Search, Power Automate, Azure Blob Storage, and RAG.

**Capabilities**
- Retrieves and synthesizes evidence across structured and unstructured sources.
- Uses metadata enrichment and chunking to improve retrieval quality.
- Grounds responses in source evidence.
- Explores role-specific AI agents for customer intelligence.

**Key learning:** Reliable enterprise AI depends heavily on data preparation, retrieval quality, evaluation, and governance—not simply model selection or prompt engineering.
